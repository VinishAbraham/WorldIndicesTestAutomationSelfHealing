# C# Selenium + NUnit + Ollama Self-Healing Test Framework

This repository contains a self-healing test framework using C#, Selenium, NUnit, and Ollama, designed to be used with the Page Object Model (POM) architecture.

## Setup

1. Clone the repository.
2. Open the solution in Visual Studio.
3. Restore NuGet packages.
4. Configure your test settings if necessary.

## Instructions

- To run the tests, use the Test Explorer in Visual Studio.
- Make sure your web driver is set up correctly.

## Usage

- Follow the examples provided in the `Tests` directory to create your own test cases.
- Refer to the `Pages` directory for the page objects that interact with the application.

## Features
- Self-healing capabilities with Ollama.
- Page Object Model structure for maintainability.
- NUnit for testing framework.
